# College Project

## Overview
This project includes a college homepage and a bank challan form built with HTML, CSS, and JavaScript.

## Implemented Files

- `index.html`
  - Homepage for “Smt. L.V. Government Polytechnic”
  - Includes:
    - header with navigation links
    - hero section with intro text and college image
    - about section describing college values
    - programs section with diploma offerings

- `form.html`
  - Bank challan form page
  - Includes:
    - customer name input
    - account type radio buttons
    - challan number field
    - bank selection dropdown
    - account number field
    - date picker
    - amount field
    - submit and clear buttons

- `style.css`
  - Styles the college homepage
  - Adds responsive layout, card design, and hover effects

- `color.css`
  - Styles the challan form
  - Adds form layout, input styling, and button interaction effects

## JavaScript Behavior

- `form.html` includes inline JavaScript:
  - `alert()` to welcome the user
  - `prompt()` to ask for the customer name
  - `confirm()` to verify form submission
  - success/cancel alerts based on user choice

## Notes
- The project uses plain HTML, CSS, and JavaScript
- No external frameworks or libraries are used
